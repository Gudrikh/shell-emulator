# Эмулятор командной оболочки

Учебный проект для практической работы №1, вариант 7.
Программа имитирует командную оболочку в графическом окне.

## Этап 1

Заголовок окна содержит имя пользователя и имя компьютера.
Поддерживается раскрытие переменных среды, например `$USERNAME`.

Реализованы команды:

- `ls` — выводит имя команды и переданные аргументы;
- `cd` — выводит имя команды и переданные аргументы;
- `exit` — завершает работу без аргументов.

Для неизвестных команд, лишних аргументов `exit` и незакрытых
кавычек выводится сообщение об ошибке.
