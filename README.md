# Эмулятор командной оболочки

Учебный проект для практической работы №1, вариант 7.
Программа имитирует командную оболочку в графическом окне.

## Этап 1. Графический интерфейс и команды

Заголовок окна содержит имя пользователя и имя компьютера.
Поддерживается раскрытие переменных среды, например `$USERNAME`.

## Этап 2. Параметры запуска и стартовый скрипт

Программа принимает параметры командной строки:

- `--vfs` — путь к файлу виртуальной файловой системы;
- `--prompt` — текст приглашения командной строки;
- `--script` — путь к стартовому скрипту.

Стартовый скрипт выполняется построчно. Пустые строки и строки,
начинающиеся с `#`, пропускаются. Ошибочные команды выводят сообщение
и не мешают выполнению следующих строк.

## Этап 3. Виртуальная файловая система

VFS загружается из CSV-файла и хранится в памяти.

CSV-файл содержит столбцы:

- `path` — путь к файлу или каталогу;
- `type` — тип объекта: `file` или `dir`;
- `content_base64` — содержимое файла в кодировке Base64;
  для каталогов поле оставляется пустым.

Для проверки подготовлены файлы `data/vfs-minimal.csv`,
`data/vfs-many.csv`, `data/vfs-tree.csv` и `data/vfs-stage4.csv`.
Для проверки ошибок загрузки также есть `data/vfs-invalid.csv`.

## Этап 4. Основные команды

- `ls [путь]` — показывает содержимое текущего или указанного каталога;
  для файла выводит его имя.
- `cd [путь]` — меняет текущий каталог. Путь может быть относительным
  или начинаться с `/`. Команда `cd` без аргумента возвращает в корень VFS.
- `whoami` — выводит имя пользователя операционной системы.
- `head файл` — выводит первые 10 строк текстового файла.
- `head -n число файл` — выводит указанное количество строк.

Команда `exit` завершает работу без аргументов. Для неизвестных команд
и неверных аргументов выводится сообщение об ошибке.

## Запуск

Требуется Python с установленным Tkinter. Сторонние пакеты
не используются.

Из корневой папки проекта запустите:

```powershell
.\run.bat
```

Пример запуска с параметрами:

```powershell
python -m src.main --vfs "data/vfs-stage4.csv" --prompt "STAGE4> " --script "scripts/startup_stage4.txt"
```

## Проверки

Запуск unit-тестов:

```powershell
python -m unittest discover -v
```

Проверки разных файлов VFS:

```powershell
.\scripts\test_vfs_minimal.bat
.\scripts\test_vfs_many.bat
.\scripts\test_vfs_tree.bat
```

Проверка команд этапа 4:

```powershell
.\scripts\test_stage4.bat
```
