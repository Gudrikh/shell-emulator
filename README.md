# Эмулятор командной оболочки

Учебный проект для практической работы №1, вариант 7.
Программа имитирует командную оболочку в графическом окне.

## Этап 1. Графический интерфейс и команды

Заголовок окна содержит имя пользователя и имя компьютера.
Поддерживается раскрытие переменных среды, например `$USERNAME`.

Реализованы команды:

- `ls` и `cd` — пока работают как заглушки и выводят переданные аргументы;
- `exit` — завершает работу без аргументов.

Для неизвестных команд, лишних аргументов `exit` и незакрытых
кавычек выводится сообщение об ошибке.

## Этап 2. Параметры запуска и стартовый скрипт

Программа принимает параметры командной строки:

- `--vfs` — путь к файлу виртуальной файловой системы;
- `--prompt` — текст приглашения командной строки;
- `--script` — путь к стартовому скрипту.

Стартовый скрипт выполняется построчно. Пустые строки и строки,
начинающиеся с `#`, пропускаются.

Пример запуска:

```powershell
python -m src.main --vfs "data/vfs-minimal.csv" --prompt "DEMO> " --script "scripts/startup.txt"
```

## Этап 3. Виртуальная файловая система

Файловая система загружается из CSV-файла и хранится в памяти
во время работы программы.

CSV-файл содержит столбцы:

- `path` — путь к файлу или каталогу;
- `type` — тип объекта: `file` или `dir`;
- `content_base64` — содержимое файла в кодировке Base64; для каталогов
  это поле оставляется пустым.

Для проверки подготовлены файлы:

- `data/vfs-minimal.csv` — минимальная файловая система;
- `data/vfs-many.csv` — несколько объектов;
- `data/vfs-tree.csv` — каталоги с вложенностью в несколько уровней;
- `data/vfs-invalid.csv` — файл с некорректным форматом.

Для запуска проверок используйте из корневой папки проекта:

```powershell
.\scripts\test_vfs_minimal.bat
.\scripts\test_vfs_many.bat
.\scripts\test_vfs_tree.bat
```

При отсутствии или некорректном формате CSV программа выводит сообщение
об ошибке загрузки VFS.

## Запуск

Требуется Python с установленным Tkinter. Сторонние пакеты
не используются.

Из корневой папки проекта запустите:

```powershell
.\run.bat
```

Тесты запускаются командой:

```powershell
python -m unittest discover -v
```
